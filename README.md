📄 Subtask 1 — GitHub vs GitLab Comparison (Worksheet 1)
 
🔹 GitHub — Key Features
 
1. GitHub Actions: Built‑in CI/CD automation for testing, building, and deploying code directly from repos.
2. GitHub Pages: Free static site hosting for documentation, portfolios, or project demos.
3. GitHub Discussions: Community‑focused threaded discussions per repo, ideal for open‑source collaboration.
 
🔹 GitLab — Key Features
 
1. Integrated DevOps Platform: Built‑in CI/CD, container registry, Kubernetes management, monitoring, and security scanning — no third‑party tools needed.
2. Built‑in Wiki & Issue Tracker: Fully integrated project management and documentation tools out of the box.
3. Self‑Hosted & Private Deployment: Full control over data and infrastructure; ideal for organizations with strict compliance/security requirements.
 
🔹 Licensing — Core Difference
 
- GitHub: Free for public repos; free tier for private repos with limits. Proprietary core — you cannot self‑host the full platform; only GitHub Enterprise (paid) offers on‑premise deployment.
- GitLab: Open‑core — the Community Edition (CE) is free and open‑source, can be self‑hosted without cost. Enterprise Edition (EE) adds paid features. GitLab also provides free public and private repos on GitLab.com.
 
🔹 Feature Comparison
 
✅ Five Common Features (Both Platforms)
 
1. Git Version Control: Full Git support — branching, merging, commits, pull/merge requests.
2. Repository Hosting: Public & private repos, web interface, file browsing, and collaboration tools.
3. Issue Tracking: Task management, labels, milestones, assignees, and linking to commits/PRs.
4. Code Review: Pull/Merge Requests, inline comments, approval rules, and diff views.
5. Team Collaboration: Organizations/groups, access control (roles/permissions), and activity feeds.
 
💡 Two Unique to GitHub
 
1. GitHub Marketplace: Thousands of third‑party integrations, apps, and APIs to extend platform functionality.
2. Social Coding Features: Follow users, star repos, activity feeds, and a stronger open‑source community discovery ecosystem.
 
💡 Two Unique to GitLab
 
1. Complete DevOps Lifecycle: Built‑in CI/CD, testing, security scanning, package registry, and deployment — all in one platform.
2. Built‑in Time Tracking & Burndown Charts: Project management tools (Scrum/Kanban boards, time tracking, sprint planning) without extra plugins.
